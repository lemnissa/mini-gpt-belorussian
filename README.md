# Mini GPT для белорусского языка

Реализовал с нуля **decoder-only Transformer (GPT-like)** для задачи **авторегрессионного языкового моделирования** на белорусском языке с фокусом на **low-resource setting**.

Проект направлен на изучение поведения Transformer-моделей при ограниченных данных и вычислительных ресурсах, а также на построение воспроизводимого baseline для дальнейших экспериментов.

---

## Ключевые результаты

* Построен end-to-end pipeline для language modeling
* Реализована архитектура Transformer без использования высокоуровневых abstractions
* Получены метрики:

  * **Validation loss:** 1.76
  * **Perplexity:** 5.82

> Эксперименты проводились при ограниченных вычислительных ресурсах и небольшом корпусе, поэтому модель рассматривается как **baseline для low-resource language modeling**, а не оптимизированное решение.

## Архитектура

Модель следует стандартной GPT-парадигме:

* Token + positional embeddings
* Стек Transformer-блоков (pre-norm):

  * Multi-head self-attention
  * Causal masking (strict autoregressive constraint)
  * Feed-forward network
  * Residual connections
* Финальный linear head

## Токенизация и представление данных

Использована **character-level токенизация**:

* позволяет избежать bias от заранее обученных subword-токенизаторов
* обеспечивает устойчивость к редким символам
* особенно релевантна в low-resource сценариях

Недостаток — увеличение длины последовательностей и сложности моделирования дальних зависимостей.

## Data pipeline

* Корпус собран из открытых источников (Wikipedia / OSCAR / C4)
* Формат задачи:

  * input: последовательность длины `block_size`
  * target: next-token prediction
* Train/validation split
* PyTorch `Dataset` / `DataLoader`

---

## Обучение

* Оптимизация: `AdamW`
* Gradient clipping для стабилизации обучения
* Валидация в процессе тренировки
* Checkpointing по лучшему `val_loss`

---

## Генерация

* Autoregressive decoding
* Контроль стохастичности:
  * temperature
  * top-k sampling

---

## Исследовательские наблюдения

* Даже при относительно низкой perplexity (~5.8)
  модель на char-level может **генерировать лексически корректные, но семантически нестабильные последовательности**, что указывает на:

  * ограниченную способность моделировать долгосрочные зависимости
  * недостаточную емкость модели / объем данных

* Character-level представление:

  * хорошо учит локальную структуру (морфология, орфография)
  * хуже — глобальную семантику
