# Mini GPT для белорусского языка

В проекте исследуется задача language modeling для белорусского языка в условиях ограниченных данных.

Реализованы два подхода:

* обучение небольшой GPT-подобной модели с нуля;
* адаптация готовой LLM через LoRA fine-tuning.

На первом этапе обучается char-level модель, которая предсказывает следующий символ в тексте.
На втором этапе используется pretrained модель, которая дообучается на instruction-данных и начинает работать в формате вопрос–ответ.

---

## Подход

### Mini GPT (с нуля)

* реализован decoder-only Transformer на PyTorch;
* используется character-level токенизация;
* данные собраны из Wikipedia / OSCAR / C4;
* обучается на задаче next-token prediction.

Модель:

* хорошо учит орфографию и локальные зависимости;
* но генерирует текст, который часто не имеет осмысленного содержания.

---

### LoRA адаптация

* используется модель `Qwen2.5-0.5B-Instruct`;
* применяется parameter-efficient fine-tuning (LoRA);
* обучаются только адаптеры, базовые веса заморожены;
* данные представлены в формате instruction / input / output.

После дообучения модель:

* начинает отвечать в формате вопрос–ответ;
* даёт более структурированные и локально осмысленные ответы.

---

## Основной результат

* модель, обученная с нуля, генерирует грамматически корректный, но семантически слабый текст;
* LoRA-адаптация улучшает структуру ответов и связность на коротких отрезках,
  но не полностью решает проблему качества языка.
